# 09 Parallel Algorithms

In this block we cover:

* Parallel computation
  * CPUs, computers and clusters as parallel processing units
  * Formal classes of parallel computer (SISD/SIMD/MISD/MIMD)
  * Embarrassingly parallel algorithms
* Vectorisation
  * Vectorisation of K-dimensional objects (tensors)
  * Vectorisation and time complexity
  * PyTorch, GPUs and automatic differentiation
* Computational graphs
  * Computation dependence
  * Parallel speedup and maximum speedup (Amdahl's law)
  * Distributed computation
* Map/Reduce
  * Accumulate/Reduce
  * The Map/Reduce parallel framework
  * Map/Reduce matrix multiplication
  * Loss functions and gradients as map-reduce operations
* Coding parallel algorithms
  * Multiprocessing with joblib
  * Overheads and chunking
  * Asynchronous computation and futures
  * Parallel hyperparameter search, and emulating the accuracy-compute trade-off

## References

### Parallel algorithms

* Chapter 27 of Cormen et al 2010 [Introduction to Algorithms](https://github.com/mejibyte/competitive_programming/blob/master/lib/Books/Introduction.to.Algorithms.3rd.Edition.Sep.2010.pdf) covers some of these concepts.
* Guy Blelloch and Bruce Maggs [A Brief Overview of Parallel Algorithms](http://www.cs.cmu.edu/~scandal/html-papers/short/short.html)
* CSinParallel [Parallel computing concepts](https://csinparallel.org/csinparallel/modules/intro_parallel.html)
* Tutorialspoint on [MISD/MIMD/SIMD/SISD](https://www.tutorialspoint.com/parallel_algorithm/parallel_algorithm_introduction.htm) and [Parallel time complexity](https://www.tutorialspoint.com/parallel_algorithm/parallel_algorithm_analysis.htm)

### Vectorisation and PyTorch

* Real Python on [Numpy vectorisation](https://realpython.com/numpy-array-programming/)
* [PyTorch](https://pytorch.org/) and its [autograd tutorial](https://docs.pytorch.org/tutorials/beginner/basics/autogradqs_tutorial.html)

### Map/Reduce and parallel Python

* Emory University notes on the [MapReduce algorithm for matrix multiplication](http://www.mathcs.emory.edu/~cheung/Courses/554/Syllabus/9-parallel/matrix-mult.html)
* Chrys Woods [Parallel Python](http://chryswoods.com/parallel_python/part1.html), including [map](http://chryswoods.com/parallel_python/map.html) and [reduce](http://chryswoods.com/parallel_python/reduce.html)
* Beyond one machine: [Dask](https://www.dask.org/) and [Ray](https://www.ray.io/) run the same map and futures patterns over a cluster.
